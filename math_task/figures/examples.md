## Injected corruptions

At evaluation, each operation step the model emits is replaced with probability `p` by a random operation drawn from the set below. Every one preserves the solution set, so the target answer is unchanged and a model that tracks the algebraic state can recover. State reports and the final `####` answer are never replaced.

```
add 1 to both sides.
add 10 to both sides.
add 8 to both sides.
divide both sides by 2.
divide both sides by 3.
divide both sides by 5.
multiply both sides by 2.
multiply both sides by 3.
multiply both sides by 4.
subtract 11 from both sides.
subtract 5 from both sides.
subtract 9 from both sides.
...
```

Applied to a real problem — the injected operation is marked `<<`, and the answer is the same before and after:

```
problem      52 = -4*(3*x + 11) - 12
true answer  -9

add 12 to both sides.                   ->  64 = -12*x - 44
divide both sides by -4.                ->  -16 = 3*x + 11
multiply both sides by 3.               ->  -48 = 9*x + 33   << injected
subtract 11 from both sides.            ->  -59 = 9*x + 22

solution set after the detour: -9
```
